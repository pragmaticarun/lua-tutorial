# Part 1: Foundations

The language itself: values, control flow, Lua's single data structure, text
processing, and functions as first-class values. By the end of Part 1 you can
read almost any Lua codebase and write small tools.

| # | Lesson | You will learn |
|---|---|---|
| 1 | [Why Lua](01-why-lua.md) | Where Lua fits, the three interpreters, REPL, scripts, stdin |
| 2 | [Syntax, Types and Values](02-syntax-types.md) | The eight types, integers vs floats, truthiness, `local`, Lua 5.5 `global` |
| 3 | [Control Flow](03-control-flow.md) | `if`, loops, generic `for`, `goto`, 5.5 read-only loop variables |
| 4 | [Tables I](04-tables-1.md) | Arrays, dictionaries, references, `#` and holes |
| 5 | [Tables II](05-tables-2.md) | Records, sets, queues, matrices, the `table` library, `table.create` |
| 6 | [Strings](06-strings.md) | Immutability, `string` library, `format`, UTF-8, binary data |
| 7 | [Patterns](07-patterns.md) | Lua patterns vs regex, captures, `gsub` with functions, parsing |
| 8 | [Functions](08-functions.md) | Multiple results, named args, varargs, 5.5 named varargs, tail calls |
| 9 | [Closures and Upvalues](09-closures.md) | Counters, private state, memoization, callbacks |

!!! tip "How to study"
    Type the examples rather than copying them, then change something and predict
    the output before running it. Do the exercises before opening the solutions.
